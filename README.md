# Tempo

A simple timer, with tasks and time attributed to them.

- Countdown timer and chronometer.
- Create tasks and attribute the running time to them.
- Task progress is stored in the local storage of your browser.

## Development

- Install the dependencies with `npm install`.
- Start the local server with `npm run dev`. The server listens on port 3001.
- Build the app for production with `npm run build`.
- Preview the production build with `npm run preview`.
